## 1. 版本概览

- **性质**：这不是「小步 rc」区间——0.2.2 是继 0.2.1 后的平台级版本：Cordis Core 4.1 / Loader 1.1 / Include 1.1 同步上移，工具执行器拆分，schedule 子系统宿主级重构，Node 最低版提高至 24.9。
- **主包依赖**（tarball diff 实测）：82 个内部包统一 bump `0.2.1-rc.5 → 0.2.2-rc.1`；**新增 4 个直接依赖**：`dsh-experimental-forge-bundle`（变更请求与工作树）、`dsh-experimental-liveshare`、`dsh-official-bundles`、`dsh-personalized-recommendations`。
- **外部 ranged 依赖全部上移**（与 rc.5 区间「解析不变」相反）：`@deepseek-ai/cordis ~4.0.5 → ~4.1.0`（实际 4.1.0）、`schemastery ~3.18.5 → ~3.19.0`、`cordis-plugin-loader ~1.0.6 → ~1.1.0`、`cordis-plugin-include ~1.0.10 → ~1.1.0`、`cordis-plugin-timer ~1.1.7 → ~1.2.0`（npm versions 实测，稳定版均已发布，`~` 范围必命中）。
- **内部包全景扫描**（registry tarball 逐文件 SHA256 对比，共 197 个包：主包直接依赖 82 + web-app 依赖合并去重 179 + 插件 host 侧补查 15，含交叉）：
  - **纯版本号 bump 6 个**（lib 逐字节相同）：`dsh-atomic-write`、`dsh-cmdline`、`dsh-file-reference`、`dsh-home-paths`、`dsh-launch-environment`、`dsh-subprocess`；
  - **新增包 10 个**（首发 `0.0.0-stage` 版本号，版本恒定不跟主线）：`dsh-client-ui-context-menu` / `-file-actions` / `-file-drag`、`dsh-message-quotes`、`dsh-deliverable-file-references`、`dsh-tool-executor-ptc`（PTC 执行器拆分产物）+ 上述 4 个主包新依赖；
  - **移除 1 个**：`dsh-client-ui-deepseek-model-label-1017`（rc.5 web-app 依赖表还有、rc.1 移除——rc.5 报告提到的「DeepSeek /models 跟随」实验期 UI 包收编进 settings-models）；
  - **其余全部有真实内容变化**。普遍模式：`lib` 少量真实变化 + 统一新增 6 个 `locale/{de,es,fr,ja,pt,ru}.json`（release notes「新增六国语言文案」，纯文档不加代码）。
- **host 侧核心服务面这次全部有真实变化**（与 rc.5 区间 21 包零变化形成鲜明对比）——`dsh-agent`(12 处文件) / `dsh-subagent`(16) / `dsh-llm`(7) / `dsh-tools`(8，执行器拆分新增 executor/pipeline/ptc 等类型族) / `dsh-session`(7) / `dsh-session-persistence`(5) / `dsh-session-title`(7) / `dsh-permission-presets`(8) / `dsh-settings`(2) / `dsh-system-prompt`(5) / `dsh-agent-default-model`(3) / `dsh-working-directory`(2) / `dsh-util-values`(4)。**但接面级核对全部通过**（见 §3）。
- **插件直接依赖的例外**：`dsh-workspace`、`dsh-pwsh-local` lib 内容零变化（仅加 locale 文件）；`dsh-brand` 纯版本 bump；`dsh-invariants` 自 0.2.0-rc.2 后继续停发（npm versions 实测，两版解析同一 tarball）。
- **cordis-plugin-timer 1.1.7 → 1.2.0**：tarball 对照为**纯新增 API**（`throttle`/`debounce` 调度方法），既有定时方法不动。
- **同 id 冲突排查**（0.1.5 workspace-files 教训）：从新版全部解包产物的 `cordis.patch.yml` 提取 265 个内置条目 id，与本仓 10 个插件 id（含首次纳入的 `momoyu-mem`）逐一比对——**零冲突**。新增内置 id 为 forge 族（`forge`/`forge-panel`/`forge-session`/`forge-worktree`/`forge-github`）、liveshare 族、`tool-executor-native`/`tool-executor-ptc`、`session-inspector`、`ui-context-menu` 等。

## 2. 用户视角差异

（以官方 release notes `v0.2.2-rc.1` 与 `docs/upgrade-guide/v0.2.2-alpha.2/` 13 篇指南为准，rc.1 无独立迁移指南目录。）

### 新功能

- **实验性「变更请求与工作树」（forge）**：在独立 Git worktree 中运行会话，可搜索文件树 + 逐文件 diff 导航、选中代码/评论交给 Agent、跟踪检查与评审状态；原「Git 工作树」入口合入（此前启用 `dsh-experimental-tool-worktree` 独立插件的用户需手动从 profile bundles 移除）。
- **实验性 `subagent_oar`**：把独立任务交给本机 Codex / Claude CLI。
- **实验性「个性化推荐」「开发者工具-统计」**：官方插件启用卡片 / 按轮次步骤查看上下文与耗时统计。
- **统一右键与键盘菜单**（`ui-context-menu` 新包，slot 可扩展）；文件预览常驻目录树与文件定位；聊天引用插入、会话复制为 Markdown；工作步骤收起保留全文；六国语言文案；插件管理富文本详情与第三方插件更新（热更新失败回滚旧版）。
- **`apply_patch` 工具**（默认关闭）：一次完成多文件增删改移，Review 中查看变更；web `standard` 预设与 dsh-base 开启，`ptc`/`cordis` 预设保持关闭。

### 行为变化（对本机使用面最重要的在前）

- **文件先读/外部修改防护默认关闭**：`fs-observation-policy` 行默认 `disabled: true`——`write` 不再要求先读、`edit` 不再校验外部修改；沙箱限制与 Review 不变。需要旧行为的 profile 显式 `- {id: fs-observation-policy, disabled: false}`（官方 guide 明确给出恢复写法）。
- **schedule 子系统宿主级重构**：模型工具改为 `schedule_create/list/view/edit`（RRULE + `target`，`schedule_update/delete` 移除）；Native/Remote API 统一为 `create/edit/list/view/catalog/history/run`，按 id 管理任意 Host 任务；子 agent 调用一律拒绝（`subagent_session`）；存储写 v2 读 v1（首次 v2 写后 v1 二进制拒开，**降级需备份**）。
- **bundle 行运行时变更不再跨重启**（Loader 1.1 + Include journal）：运行时对 bundle 行的变更（如 UI 里禁用插件写入 `disabled: true`）只更新内存 patch，**重启后恢复**；外部编辑 patch 文件仍优先。本仓 AGENTS.md §2.3 的「bundle 行加 `disabled: true` 应急停用」手法在新版语义 = HMR 即时生效、重启即失效。
- **本步模型在提示词组装与 pre-step 前固定**，重试保留同一选择；插件应通过 `agent.model` 选择模型，`agent/request` 不再允许改路由。
- **原生与 PTC 工具执行拆为按 Agent 作用域选择的插件**（`tool-executor-native`/`tool-executor-ptc` 新条目）；PTC Node 控制通道改 birpc，SSH 协议 2→3（自部署 bootstrap/SSH helper 需同步升级）；PTC 取消分类 ABORTED 替代 CODE_RUN_FAILED；旧 `tools.mode`/`DSH_TOOLS_MODE` 需迁移。
- **工具可按步骤条件启用**（模型声明、PTC 绑定、执行准入一致）；Node PTC 新增 VM Script 模式。
- 全局与项目 AGENTS.md **分别**使用 maxBytes 预算（项目指令不再挤掉全局指令）；未声明容量的自定义模型默认 1M/128K（十进制）；远程连接默认启用 WebSocket 压缩（`websocketCompression` 可关）；Web 静态资源 ETag/304；Ralph 循环与会话搜索退出实验性列表；pi-ai 升 1.3.0（工具参数格式错误在执行前终止响应）。
- **Node.js 最低版本提高至 24.9**（本机 node v24.13.1 满足）。

### 修复（节选，完整见 release notes）

- 插件依赖子路径/包内导入/自引用按 ESM 规则解析（shigma）；Git 插件安装 HTTPS 失败自动转 SSH；含 prepare 脚本的 Git 插件安装显示授权与重试选项。
- Windows：管理员/Sandbox 下受限沙箱命令无法启动的修复；持久 Bash（macOS）感叹号历史展开修复。
- 预设往返切换后委派工具暂缺修复；已压缩会话历史加载停更修复；`~`/`~/` 路径主目录展开；grep 空 include 不再失败。
- 上下文前缀缓存复用（系统提示词未变时）；切小模型前先压缩历史；后台任务等待可被插话解除。

### 配置与 preset

- `dsh-web-app` 默认 patch 新增 `entry-customization` 之外的条目族：`forge` 族、`liveshare` 族、`tool-executor-native`/`tool-executor-ptc`、`session-inspector`、`ui-context-menu`、`ui-file-actions`/`ui-file-drag`、`personalized-recommendations` 等（tarball diff 实测 changed=7/added=12）。
- `dsh-base`：`fs-observation-policy` 默认 disabled + `tool-fs` 开 `applyPatch`（headless/SDK/ACP 与 web standard）；`tool-worktree` bundle 仍存在但入口被 forge 取代。
- **无 preset schema 破坏**：`cordis-plugin-loader/include` 升 1.1 后 patch 语法兼容；官方升级指南仅要求 worktree 独立插件用户手动清理 profile bundles 行。

### 正式迁移指南补充核对（2026-11-12 增补）

rc.1 发布时无独立迁移指南（上文 §2 以 v0.2.2-alpha.2 的 13 篇为准）；rc.2 时点官方补发了 `docs/upgrade-guide/v0.2.2-rc.1/`（18 条）。核对结论：

- **插件接面零命中（无需改插件）**：`Session.append` 双 overload（单事件/数组，包装器需两形态都支持）、`BundleInfo.updatable → .update`（plugin-manager API）、`ManagementError` 新增 `unexpected-package` 码、`interrupt_agent` 工具面——本仓 10 插件源码 grep 全部零命中（2026-11-12 实测）。
- **部署配置面核对项（非代码改动）**：
  - `subagent-interrupt-default`：base 与 web 内置 preset 的 `tool-subagent-control` 行默认 `interrupt: false`——模型不再拿到 `interrupt_agent` 工具。schedspawn 走 `ctx.subagents` 服务 API（指南明示服务面中断保持可用），不受影响；自定义 preset 若挂该行需确认 interrupt 语义——本会话（momoyu-common 组合）工具清单含 `interrupt_agent`，实际保留 ✓，留 preset 漂移核对正式确认。
  - `runtime-context-reminders`：runtime-context 快照消息改为带 `<system-reminder>` 包裹 + `source.kind: 'runtime-context'`——momoyu-mem 每日整理的「过滤注入」兼容（壳文本与既有 system-reminder 形态一致；后续整理流程建议优先按 `source.kind` 判定）。
- **⚠ 指南目录与实际生效版本的错位（安装树实证）**：该目录是「rc.1 线集合」，但其中 `dsh-doc-skill`（Creator 四 skill → `dsh-doc` 统一）与 `archive-worktrees`（归档清理 worktree + `forge-worktree`/`optional-forge-panel` 行更名）两条经本机 rc.1 安装树实证**尚未生效**（`dsh-agent-preset/skills/` 仍是旧四 skill）——属 rc.2 变化，迁移面记入 rc.2 预研（见下）。
- 其余条目（account-*/cua-*/forge-* UI/terminal-*/web-search-billing/window-drag-regions 等）为桌面端、forge 新功能、账号计费与 UI 面，不触插件接面。
