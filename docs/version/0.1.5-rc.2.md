### 细节与注意点

- **本节最重要结论：6 个插件在 0.1.5-rc.2 下全部"无需改动"，且这次的"无需改动"是字节级证明**——rc.1→rc.2 的 host 侧源码变化只有一行注释（`packages/feedback/message-feedback/src/types.ts`），上版报告在 rc.1 树上做过的全部 `文件:行号` 级接面验证对 rc.2 原样成立，本次仅做抽样正向复核。
- **升级的动作面为零**：上版的唯一必做项（`momojie-common` persona 改 `prefix`/`suffix`）若尚未做仍是 rc.2 的前置条件（preset 包两版内容一致，规则没变）；已做完则 rc.2 无新增动作。
- **peer 版本范围（机械跟进项，非阻塞，延续上版结论）**：5 个带 peer 的插件仍钉 `@deepseek-ai/dsh-*@^0.1.1-rc.2` 系，按 node-semver 预发布规则匹配不到 `0.1.5-rc.2`；本机 junction 解析与运行时不受影响，`dsh plugin add` 路径会有告警。workspace-env 无 peerDependencies，不在此列。
