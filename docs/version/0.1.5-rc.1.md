## 3. 用户视角差异（最实用）

1. **出站网络代理**（新包 `dsh-http-proxy`，区间内 merge `7169660d33` #3198 + `76fda72979` #3471；新用户指南 `docs/user/guide/network-proxy.md`，+85 行×2 语言）：模型调用、web 搜索、网页抓取、HTTP 型 MCP server 的出站请求统一走标准 `HTTPS_PROXY`/`HTTP_PROXY` 环境变量，**启动时读取**；带凭据的代理 URL 写在变量里且永不回显。两点部署注意：① 项目 `.env`（随 git clone 来的）**不能**设代理变量——DSH 拒绝启动而不是让仓库决定流量走向，`~/.dsh/.env` 可以；② 部分路径按设计直连（指南"What stays direct"节）。对本机远程部署（frp+nginx）无直接影响——代理只管 DSH 的**出站**流量
2. **Models 页与 provider 配置面重写**（`docs/user/guide/providers.md` +87/−48，区间内 #3792 base-url 校验、#3791 中文模型显示名、#3824 deepseek-flash 模型目录等）：内置 provider 一览（`anthropic`/`openai`/`moonshotai`-Kimi/`zai`-GLM 等）；自定义 provider 必须三选一声明 API 协议（`openai-completions` / `openai-responses` / `anthropic-messages`）；"Fetch available models"改为对任意端点的可搜索模型发现 picker；删除的默认模型会让输入框阻塞在"Select model"；高级字段（reasoning effort、超时、重试等）全部归口 `$DSH_HOME/settings.yaml`
3. **Electron 桌面应用进入主线**（`ba05b7d49d` #3413 feat/electron，122 文件 +12,259）：CLI launcher 显式拒绝 `--profile desktop`（bin.js 实证），desktop 形态由 Electron 应用专管；`dsh plugin --profile ... desktop` 同样被拒。对本机 CLI/web 部署无影响，但升级后若脚本里误写过 desktop profile 会得到明确报错
4. **会话日志 v3**（`7b1c989332` #3631 release/session-log-v3）：会话事件词表结构性变化——`assistant/chunk` 事件**删除**，`assistant/message` 改为内嵌精确压缩流（`stream: AssistantStreamRecord[]`），新增 `assistant/attempt`（未产生可见消息的失败/重试/取消尝试）与 `system/message`（模型可见系统提示词的表面记录）；每次模型尝试落一条 durable settlement。**磁盘产物默认不变**：逻辑名 `session.jsonl`、默认压缩仍 zstd（`session-persistence-jsonl/src/index.ts:66` `DEFAULT_COMPRESSION: JsonlCompression = 'zstd'` @183f08e9c6），会话目录布局与 header 字段（`cwd`/`parentSession`/`origin`/`delegationDepth`）不变（`core/session/src/index.ts:117` 仍在校验 parentSession）
5. **Web 侧栏体系大改**（#3588/#3798/#3859/#3909 一串 + #3890 sidebar-image-preview）：AppFrame 网格从"sidebar + 中列 + details"变为 **`sidebar | 1fr | rightbar` 三列**，新增官方 `rightbar` 槽位与 `data-rightbar-collapsed/-fullscreen/-instant` 根属性；`data-details-collapsed` 属性**消失**（`ui-layout/src/client/AppFrame.tsx:205-215` @183f08e9c6 实证）。这直接影响本仓 dsh-right-dock 的 DOM 锚点策略（见 §4）。另：mermaid 预览合入后又回退（#3710 → #3901 revert，净零）

### 细节与注意点
