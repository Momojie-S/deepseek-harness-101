## 3. 用户视角差异（最实用）

rc.8 之后的新增（本报告增量部分）：

1. **DeepSeek 视觉模型 + 多模态请求**（`4fa38d6a23` feat(llm-deepseek): publish the vision model、`7078918b30` support multimodal requests）：deepseek 路线原生视觉能力上线。本机主力走 GLM/zai 路线，无直接感知；未来需要"官方 DSH 自带视觉路线"时可用
2. **图片管线统一与 grounding 精度**（`d29855f97c`/`72b204afa1`/`83a526eea1`/`6e17c20804`）：master 与 Files 请求管线统一、上传信封扩展、确定性规范化图片编码；**`read_image` 现在报告降采样后的尺寸与坐标比例**——喂图后问坐标时模型拿到的尺寸信息与实际像素对齐，VLM grounding 坐标换算更可靠
3. **凭据体系强化**：durable credential records（`86a9f8c862`，凭据记录与引用分存）、ask-human 授权流（`732a7361f5`，缺凭据时向用户要而不是直接失败）、pi-ai 路线 sign-in（`57c5f017ac`）、预发布 flat 凭据文档启动自动升级（`933d1f2ab2`）
4. **webserver 结构化 index 注入**（`156bd075a9`）：插件往 index.html 注入脚本/样式从 raw 字符串 tap 升级为类型化行表（`webserver/index-inject` 事件），raw `tapIndex` 保留为逃生口——纯 additive，现有插件无感
5. **Web UI**：`ask_user_question` 多行回答（`9616790b6c`）、宽表格按列数自适应 + 悬停才出滚动条（`000ab970f3`/`c9ce61136d`）、近满 cache-hit 精度保留（`a4da0f40d5`）

### 细节与注意点

- **dsh-workspace-env 的覆盖边界（非破坏，需知悉）**：新持久 pwsh 工具（`tool-pwsh-persistent`）走 `ctx.terminals` PTY 路径，其子进程环境由 `terminal-bash` 的 `childEnvironment()` 组装（scrub 基座 + TERM 等），**不经过 `ctx.shell.spawnSpec`**——workspace `.env` 注入不覆盖持久 shell 会话。本机 web profile 的自定义 preset `ptc-early-compact`（code 基底）用的是 one-shot `dsh-tool-pwsh`（走 `ctx.shell`，被包裹），现状不受影响；将来若改用 persistent shell 栈（如 minimal preset 在 win32 的形态），.env 注入会静默失效，届时需要新的注入路径（PTY 侧无单一收口点，`terminal-bash` 的 `childEnvironment` 不是插件可包装的公开面）
- **peer 版本范围（机械跟进项，非阻塞）**：workspace-mcp / subagent-model 的 peerDependencies 仍是 `^0.1.0-rc.6` 系。按 node-semver 预发布规则，`^0.1.0-rc.6` **不能**匹配 `0.1.1-rc.2`（预发布版本只与同 tuple 的 comparator 匹配）——升级 DSH 后建议把这批范围机械 bump 到 `^0.1.1-rc.2`。本机插件经 junction 指向 DSH 安装树解析，运行时不受此影响；影响面是 pnpm 安装告警与 `dsh plugin add` 路径的严格解析
- **subagent 产品线大改与本插件无关**：subagent 组 +5099 行集中在 `subagent-codex`/`subagent-claude-code`（Bundle 化、命名实例、非交互权限模式）——那是 host 面产品 provider；`subagent-model` fork 的 `tool-subagent` 契约面稳定

## 5. 升级建议

- **可以升**：5 个插件无一被 0.1.1-rc.2 破坏；全部耦合接口（含 private `spawnSpec`）在新版逐一验证仍在，且多为字节级一致
- **先后顺序**：
  1. 升级 DSH（重装全局包；新依赖 `dsh-tool-pwsh-persistent` 随主包装入，rc.8 报告提到的 `dsh-host-apiproxy` 同理已在树上）
  2. （机械项）bump 两个插件的 peerDependencies 到 `^0.1.1-rc.2`，重跑各插件单测 + 原子构建
  3. 重启 web 服务
  4. 冒烟：web 开会话确认 5 个 bundle 插件加载、pwsh 调用带 workspace `.env`、`.dsh/mcp.servers.yml` 的 server 注册日志（`[ws-mcp] server "xxx": 注册 N 个工具`）、文件面板与 right-dock UI 正常
  5. 核对 `ptc-early-compact` 漂移：code preset 全区间仅注释变化，预期零漂移，快速 diff 确认即可（重套流程见 `docs/usage/agent-presets.md`）
  6. （可选）cherry-pick subagent-model 的 diagnostic 文案同步（~6 行）
- **升级后优先验证**：无高危项。次优先：多模态/贴图会话若常用，观察图片管线统一后的行为；`read_image` 降采样尺寸报告对 VLM 坐标问答是改善，可顺带验证本机 grounding 流程
