## 3. 用户视角差异（最实用）

1. **多图请求不再撑爆图片上限**：`dsh-llm` 新增 `offloadRequestImages`——请求历史里累计 base64 图片超限时，从最老开始替换为 `[image omitted to keep the request within its image limit; ...]` 占位文本（`OFFLOADED_IMAGE_TEXT`）。多轮贴图的会话更稳。
2. **中断的回答保留已输出前缀**：流被取消时 `BlockAssembler.interruptedBlocks()` 把已流出的文本/思考前缀定稿为 `assistant/message` 事件（带 `interrupted: true`，`dsh-session` 事件类型同步扩展）——中断不再丢掉已见内容。
3. **LLM 瞬时错误重试默认 2 → 5 次**（`retry-policy`）：弱网/限流场景更抗抖；显式配置过 `maxRetries` 的不受影响。
4. **子代理失败诊断更透明**：provider 可在 `SubagentResult.diagnostic` 填非助手侧失败细节（≤4096 字节），`settleRun` 与 `tool-subagent` 的错误文案都会带上——后台子代理任务失败时 `job_output` 的 detail 更有信息量。
5. **Agent Teams（run_code 宿主新面）**：`dsh-tool-cordis` 新增一整套 team 服务（roster、peer 消息、任务板、wait）。对只把 run_code 当多步编排用的场景是纯增量。
6. **minimal preset Windows 化**：win32 上 minimal 从"只有 bash"变为"只有 pwsh"（含持久 pwsh shell，新包 `dsh-tool-pwsh-persistent`）。标准/创造/code preset 不受影响（本机主用 web + 自定义 preset，无感）。
7. **session 引用/召回基础设施**（`dsh-session-reference` 大改）：跨 session 引用消息源、compaction 生命周期事件、session 标题事件——属平台层铺设，配套 UI/工具面后续版本跟进。
8. **locale 回退链 zh → en**（client runner）：非中文界面文案缺失时的兜底语言换了，中文用户无感。
9. 破坏性变更：**未发现**——主包 lib 零变化、CLI/工具注册面未见删改；唯一改名 `SubagentReportDelivery: 'wakeup'→'next-step'` 是类型层值域改名，仅影响直接引用该值的代码（本仓插件均未引用）。

## 5. 升级建议

- **可以升**：本仓 5 个插件无一被 rc.8 破坏；全部耦合接口（含 private `spawnSpec`）在 rc.8 产物中逐一验证仍在。
- **先后顺序**：① 升级 DSH（重装全局包，注意新依赖 `dsh-host-apiproxy` 会随主包装入）→ ② 重启 web 服务 → ③ 冒烟：web 开会话确认 5 个 bundle 插件加载、pwsh 调用带 workspace `.env`、`.dsh/mcp.servers.yml` server 注册日志、文件面板与 right-dock UI 正常 → ④（可选）cherry-pick subagent-model 的 diagnostic 文案同步 → ⑤ 核对 `ptc-early-compact` 漂移：rc.8 的 code preset **仅注释变化**、无功能字段变化，预期零漂移，快速 diff 确认即可。
- **升级后优先验证**：无高危项。次优先：多图会话（若常用贴图，观察 offload 占位文案是否符合预期）、后台子代理失败时的 detail 文案变化。

## 6. 方法与局限

- **硬证据**（tarball 对比）：§2 包级清单、§3 diff 细节、§4 接口存在性验证，均来自 `$env:TEMP\dsh-verdiff` 下两版 tarball 解包对比与 `git diff --no-index`（66 个内部包全覆盖逐 lib diff，"仅 package.json 变化"的结论可靠）。
- **源码仓证据**：仅 checkout 快照 `47f943859b`（shallow，无法做区间 log）；本版**没有**源码仓辅证，所有结论单源依赖 tarball。
- **局限**：
  - `dsh-tool-web`、`dsh-plan-mode`、`dsh-web-app`、`dsh-host-apiproxy`、`dsh-client-ui-agent-preset` 只有规模统计未逐行核对，§2/§3 中相应描述标注了"未逐行核对"；不影响 §4 插件结论（这些包不在任何插件的依赖面上）。
  - shallow clone 是任务书已预告的限制；若未来调查需要 PR 级归因，需先 `git fetch --unshallow`。
  - `dsh-tool-pwsh-persistent` 在 npm 上不存在 rc.7 版本（`npm view versions` 仅 rc.8）——判断为"新包"，但主包 rc.7 的 package.json 已写了 `^0.1.0-rc.7` 依赖声明，说明该包 rc.7 版本**可能发布后被撤回或从未成功发布**，此处未深究。
